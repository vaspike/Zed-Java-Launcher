Why Java Launcher?

重构 Java 本地微服务调试体验

直击多微服务开发痛点，提供专为现代轻量级编辑器定制的启动与调试管线。

动态 JDWP 端口隔离

告别 Address already in use: 5005！Java Launcher 自动为每个微服务分配并协商专属调试端口，支持 10+ 服务并发断点调试，零端口冲突。

微服务一键编排 (Group Launch)

只需声明启动顺序与延时（如网关启动后延时 2s 启动订单服务），一键即可 Group up、Group restart 优雅重启或 Group down 批量停止。

AST 毫秒级智能扫描

利用 Tree-sitter 高性能语法分析器与 Maven 反应堆模型，零 Java 进程开销，毫秒级扫描 @SpringBootApplication、main 入口与测试类。

双向无缝迁移与互通

从 VS Code 迁移到 Zed？只需一条命令 java-launcher init --from-vscode，自动将旧配置与聚合启动无损转换为 Zed 专属配置。

Dual-Engine Architecture

两种编辑器，同样的极速体验

针对 Zed 的极简键盘流与 VS Code 的可视化交互深度定制，量身打磨。

⚡

Zed Edition

Rust 原生内核 + WASM

专为 Zed 编辑器量身打造。采用纯 Rust 编译的原生 CLI + WASM 扩展，内存占用低于 10MB，自动由 Zed 插件商店拉取运行。

  • ✓ 极速 Run 模式与 Debug 模式分离：日常运行无需挂载调试器，无任何额外 RAM 开销。
  • ✓ Zed 专属 DAP 调试适配器：完全接管 Zed 调试面板，一键调试 JL-Group-<group>。
  • ✓ 自动补全 Schema：编辑 config.json 时自动弹出全工程可用服务下拉提示。
  • ✓ 洁癖模式 (Clean Mode)：防面板污染，避免数十个服务充斥 Zed 命令面板。
  • ✓ 安全自动备份与日志清空：修改配置自动时间戳备份，一键清空后台日志。

VS Code Edition

提供 Visual Studio Code 活动栏 (Activity Bar) 树状视图，通过图形化交互完成 Spring Profile 切换、聚合配置与进程管控。

Get Started

30 秒快速上手

挑选适合您工作流的安装方式

1

从 Zed 插件中心安装

打开 Zed，按 Cmd+Shift+P 搜索 zed: extensions，搜索 Java Launcher 并点击安装。

Zed Command Palette -> zed: extensions -> Search "Java Launcher"
2

初始化工程配置

在任意 Java / Spring Boot 工程中，按快捷键唤起命令并执行初始化：

Cmd+Shift+P -> task: spawn -> [Java Launcher] Initialize Project
3

一键运行或调试

打开左侧 Debug 面板，选择 JL-<ServiceName> 或 JL-Group-<GroupName> 点击启动即可享受无冲突断点调试！

1

从 VS Code 插件市场安装

打开 VS Code 扩展商店，搜索 Java Launcher，点击安装。

code --install-extension River.java-launcher
2

使用 Activity Bar 树形面板

安装后活动栏将出现 Java Launcher 图标，自动扫描当前工程所有入口，点击服务名称右侧 ▶ 即可运行或配置聚合启动。

1

通过 Cargo 安装 (全平台)

如果您已安装 Rust 工具链，可直接编译安装最新稳定版：

cargo install --git https://github.com/vaspike/zed-java-launcher
2

或下载 GitHub Releases 预编译包

提供 macOS (Apple Silicon / Intel)、Linux (x86_64 / arm64) 以及 Windows 的独立预编译二进制压缩包。

curl -sL https://github.com/vaspike/zed-java-launcher/releases/latest
